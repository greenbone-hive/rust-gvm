# rust-gvm contribution agreement

`rust-gvm` is licensed under `AGPL-3.0-or-later`. To preserve the project's
ability to relicense its code in the future, contributions are licensed under
`MIT-0` and immediately relicensed under the project's current
`AGPL-3.0-or-later` license. This contribution agreement does not change the
license applied to the repository.

Please read and commit [`template/template.txt`](template/template.txt) as
`[Name].md` in this folder with your first pull request. A valid Git
`user.name` and `user.email` is sufficient.

Example usage:

```console
# Check that user.name and user.email are configured.
$ git config --list
user.email=Jane.Doe@example.com
user.name=Jane Doe

# Commit the template.
$ cd {path_to_rust-gvm}/rust-gvm/RELICENSE
$ cp ./template/template.txt JDoe.md
$ git add JDoe.md
$ git commit
```
