# Documentation Archive

This directory preserves completed plans, implementation prompts, design
snapshots, and dated audits for historical context. Its contents are
non-normative: they may describe branches, APIs, dependencies, test counts, or
workflow behavior that no longer exists.

Use the active documentation instead:

- [`../STATUS.md`](../STATUS.md) for implemented behavior and coverage
- [`../SUPPORT_MATRIX.md`](../SUPPORT_MATRIX.md) for qualified GMP support
- [`../ROADMAP.md`](../ROADMAP.md) for current follow-up work
- [`../typed-execution.md`](../typed-execution.md) for the request/response model
- [`../agent-code-map.md`](../agent-code-map.md) for contributor orientation

## Contents

- [`implementation-prompts/`](implementation-prompts/) — one-time coding and
  review prompts retained after their work was completed
- [`specs/`](specs/) — completed or superseded OpenSpecs and test plans
- [`design/`](design/) — superseded design proposals and RFCs
- [`plans/`](plans/) — retired branch and delivery plans
- [`audits/`](audits/) — dated audit snapshots; current policy remains in the
  active documentation tree

Forward-looking specifications that still describe proposed work remain in
the repository's top-level [`spec/`](../../spec/) directory.
