# rust-gvm v0.7.0

rust-gvm v0.7.0 completes the canonical typed-request migration across the
five-crate workspace. Every supported GMP operation now has one authoritative
complete request type shared by encoding and client execution. Transitional
option bags, free XML builders, and duplicate forwarding facades have been
removed or explicitly retained only where compatibility policy requires them.

This is an intentional pre-1.0 breaking release. Callers upgrading from v0.6.0
must replace legacy split arguments and option structures with the canonical
`*Request` values documented in the
[v0.7.0 migration guide](https://github.com/greenbone-hive/rust-gvm/blob/v0.7.0/docs/v0.7.0-migration.md).

Highlights:

- complete typed request/response execution through `GmpClient::execute`;
- fail-closed request validation before capability checks or transport;
- explicit version and semantic capability gates for newer gvmd operations;
- stateful mock-server coverage for canonical request families;
- preserved low-level `send`, `call`, and custom-codec escape hatches;
- release binaries for five targets, a multi-platform GHCR image, CycloneDX
  SBOMs, checksums, and Sigstore build-provenance attestations.

The release artifacts are built from the immutable `v0.7.0` tag and verified
against its exact qualified commit before publication completes.
