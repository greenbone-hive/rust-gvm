# 2026-09-17 — Canonical GMP Requests Begin Landing

## Typed Execution and Canonical Requests
- Pull request [#604](https://github.com/greenbone-hive/rust-gvm/pull/604) updated rustls to 0.23.45, clearing `RUSTSEC-2026-0285`, and pull request [#597](https://github.com/greenbone-hive/rust-gvm/pull/597) then promoted typed request execution to `main`.
- Pull request [#606](https://github.com/greenbone-hive/rust-gvm/pull/606) established the canonical request contract: fallible validation and encoding, semantic capability classification, a structured request-error boundary, ADR 0002, and a checked inventory of 911 public request surfaces.
- Pull requests [#608](https://github.com/greenbone-hive/rust-gvm/pull/608), [#610](https://github.com/greenbone-hive/rust-gvm/pull/610), [#612](https://github.com/greenbone-hive/rust-gvm/pull/612), [#614](https://github.com/greenbone-hive/rust-gvm/pull/614), and [#616](https://github.com/greenbone-hive/rust-gvm/pull/616) merged the first bounded migrations for target, alternate-target, agent-group, agent, and integration-configuration requests.
- Pull request [#618](https://github.com/greenbone-hive/rust-gvm/pull/618) is open with green CI to migrate the port-list family, remove redundant options/builders, and validate port ranges before transport.

## CI Regression
- Security checks remain green, but `main` CI now fails when its downstream E2E dispatch builds `clawosiris/rust-gvm-e2e-tests` against the newly removed target builders and options. The E2E runner needs to follow the canonical target request API before the protected main workflow can recover.
