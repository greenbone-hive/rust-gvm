# 2026-09-16 — Typed Execution Gains Actionable Support States and a Security Gate

## Typed Execution Release Track
- Pull request [#597](https://github.com/greenbone-hive/rust-gvm/pull/597) now models command support as explicit actionable states shared by public queries and execution, distinguishing discovery-required, insufficient-version, not-advertised, and unknown-command cases while retaining the raw/custom escape hatch.
- Issue [#602](https://github.com/greenbone-hive/rust-gvm/issues/602) proposes making complete request types the canonical GMP input model. Architectural review keeps that breaking redesign out of the current promotion and requires an explicit release boundary, superseding ADR, and auditable public-surface migration plan.

- The refreshed security matrix on #597 now fails Cargo Audit for that advisory, while its remaining CI and security checks pass.
